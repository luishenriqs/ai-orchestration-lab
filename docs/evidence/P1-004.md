# P1-004 — Tentativas, reconciliação e rollback

Implementados eventos numerados imutáveis com encadeamento SHA256 e projeção attempt.json recuperável; CREATE exclusivo; transições restritas P0 §17.2; consistência temporal e de encerramento; processo identificado pelo boot_id e starttime Linux, além de PID/executável. Reconciliação não cria nova tentativa nem retry. Falha ao ler identidade por motivos diferentes de ausência do processo bloqueia a operação.

Rollback valida registro externo à fixture, raiz Git e base_commit; arquiva cada conteúdo afetado e diff fora da fixture antes de restaurar arquivos individualmente. Não usa reset/clean. A criação mínima de fixture foi antecipada de P1-005 para exercitar rollback com Git real; P1-005 acrescentará execução e isolamento. Nenhum schema normativo alterado.
