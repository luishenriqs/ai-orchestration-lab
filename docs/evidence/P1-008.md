# P1-008 — Validação integrada

Implementados exatamente os 16 cenários numerados em P1 §6/P1-008. Os identificadores locais P1-008-01..16 mapeiam os números oficiais, sem inventar nomenclatura normativa. Cada caso registra objetivo oficial, condições iniciais, procedimento, esperado/observado, PASS/FAIL/BLOCKED, hashes e artefatos. RED de 16 testes falhou funcionalmente no stub; logs preservados. Primeiro GREEN teve importação não utilizada, corrigida sem alterar critérios; GREEN-02 passou 16/16.

Auditoria local adicional reproduziu dois defeitos em P1-008-audit-red.log: lock de transição órfão bloqueava reconciliação e TASK-READY não exigia concordância de executor/identidade da fixture. Correções: lock com token de processo e arquivo de owner abandonado preservado; vínculo adicional de execução/tentativa/executor. Regressão-02 passou 77/77. Validação foi reforçada para exigir prova preventiva e snapshot de governança selados, além de registrar decisões explícitas nos casos de fault injection; regressão-03 passou 77/77.

Decisões mínimas adicionais:

- DEC-EXEC-06: executor P1 é adapter de comportamentos sintéticos fixos, com src/sum.cjs como único mount persistente de escrita. Novos formatos de tarefa/caminho não são inferidos a partir de texto livre. Contratos gerais não ampliam essa política.
- DEC-EXEC-07: testes de cenários #4 e #12 primeiro comprovam prevenção pelo SO; depois o host injeta alteração real somente na fixture para comprovar também detecção. #13 injeta symlink para sentinel sintético irmão da fixture. Nenhuma injeção ocorre em dados preexistentes ou em outro repositório.
- DEC-EXEC-08: dados sintéticos de revisão/aprovação são explicitamente identificados; o PR-GATE positivo exercita a lógica e não representa revisão independente/homologação do projeto.
- DEC-EXEC-09: scripts de teste usam runner Node serial com contagem individual. Segurança do subprocesso continua sendo bubblewrap, independente do isolamento do runner de testes. Módulos novos foram formatados pelo printer da versão TypeScript já fixada; nenhuma dependência foi adicionada.
- DEC-EXEC-10: artefatos por execução são imutáveis em diretório UUID; relatórios principais são ponteiros para execução mais recente. Verificador independente de hashes recalcula os bytes arquivados.

Validação final após formatação: 77 testes aprovados, typecheck/build aprovados, cobertura nativa dos módulos carregados 94,68% linhas / 83,41% branches / 98,47% funções. A CLI foi executada separadamente: 16 PASS, zero FAIL/BLOCKED; 306 artefatos tiveram hashes recalculados. Execução anterior à formatação e seus logs/artefatos também preservados. Cobertura não abrange a CLI não carregada pelo runner; a CLI e o verificador são exercitados nos comandos seguintes da validação final.
